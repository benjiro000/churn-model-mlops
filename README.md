# Churn model: DEV → PROD workflow

Trains a logistic regression that predicts telecom customer churn and checks it before it can reach `main`.

## Files
- `train.py`: trains the model and saves it, with metadata, in `models/`
- `check_model.py`: the gatekeeper's check (same input columns, valid probabilities, test ROC AUC of at least 0.80)
- `data/churn.csv`: the data
- `environment.yml`: the conda environment (Python 3.11)

`models/` is generated by `train.py` and is not committed.

## Run it
```bash
conda env create -f environment.yml -n project-env
conda activate project-env
python train.py
python check_model.py
```
